# Анализ заказов из Яндекс Маркета с помощью pandas

Этот проект представляет собой Jupyter Notebook, созданный для анализа выгрузки заказов из личного кабинета Яндекс Маркета за период. Работа велась с реальными бизнес-данными, с целью расчёта выручки, издержек и анализа по товарам и статусам заказов.

## Используемые инструменты

- Python 3.10+
- pandas
- Jupyter Notebook (локально)

## Описание входных данных

В отчёт входили следующие листы Excel-файла:

- `Сводка` — общая информация о периоде выгрузки, без детализации по заказам и товарам.
- `Транзакции по заказам и товарам` — список заказов с привязкой к товарам, ценам и статусам.
- `Услуги и маржа по заказам` — расходы на услуги Яндекса (комиссии, логистика и др.) на уровне заказа.
- `Заказы с умн. ценообразованием` — **не использовался** в текущем анализе.

## Цели анализа

1. **Очистка и подготовка данных:**
   - Удаление устаревших строк (например, 2022 года).
   - Удаление строк без номера заказа.
   - Замена пустых значений в колонках с денежными данными на `0`.

2. **Анализ по SKU и статусу:**
   - Сумма к переводу на счёт магазина.
   - Расходы на услуги Яндекса.
   - Средняя и медианная цена, квантиль 90%, мин/макс цены по товарам.

3. **Анализ только по статусу:**
   - Повторение п.2 без деления по SKU.

## Ключевые шаги реализации

- Загрузка и очистка данных (`dropna`, `fillna`, удаление пустых колонок).
- Объединение листов `Транзакции` и `Услуги и маржа` по номеру заказа.
- Пропорциональное распределение расходов на услуги Яндекса между товарами в заказе.
- Группировка и агрегация данных с помощью `groupby` и агрегатных функций.

## Результат

- Универсальный инструмент для внутренней аналитики магазина на Яндекс Маркете.
- Возможность легко адаптировать и масштабировать под новые выгрузки.
